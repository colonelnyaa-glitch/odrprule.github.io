# ODRP Rules

GitHub Pages用の静的サイトです。カテゴリーは参考画像と同じ階層構成です。

- 基本ルール・禁止事項
- 犯罪関連
- 職業関連
- その他

`index.html`、`style.css`、`script.js` をリポジトリ直下へアップロードしてください。


## 車両価格一覧
`vehicle-prices.html` を車両価格カテゴリー内へ埋め込み済みです。検索・カテゴリ絞り込み・価格順・積載量順に対応しています。

## 管理画面
`admin.html` を開くと、サイトをプレビューしながら文章・リンク・画像パスを編集できます。
編集後は「index.htmlを書き出す」を押し、生成された `index.html` をGitHub上の元ファイルと置き換えてください。

## ビジュアル管理画面

`admin.html` を開くと、Figma / STUDIO風のビジュアル編集画面を使用できます。

- プレビュー上の要素をクリックして選択
- ダブルクリックで文章を直接編集
- 文字、リンク、画像、色、余白、サイズ、枠線などを編集
- 要素の複製、削除、並び替え
- PC / タブレット / スマホ表示
- 元に戻す / やり直す
- GitHubへ直接公開
- GitHubコミット履歴の確認と過去版への復元

### GitHub設定

Fine-grained personal access token を作成し、対象リポジトリの `Contents: Read and write` 権限を付与してください。管理画面右上の「GitHub設定」にユーザー名、リポジトリ名、ブランチ、トークンを入力します。トークンはセッションストレージにのみ保存され、リポジトリのファイルには書き込まれません。

## Visual Editor

管理画面は `admin.html` です。ODRP用の初期設定として、GitHubユーザー名は `dreamuuu-0510`、リポジトリ名は `odrprule.github.io`、ブランチは `main` が入力されています。実際のリポジトリ名が異なる場合のみ、GitHub設定から変更してください。
